# Dataset Name 1
  Customer IT Support – Ticket Dataset

- Source
  https://www.kaggle.com/datasets/tobiasbueck/multilingual-customer-support-tickets

- Rows
  Preview: 2,000 tickets; full versions up to 20k+ and a 50k expanded variant

- Columns
  Subject, Text (email body), Department/Queue (Software / Hardware / Accounting), Priority (1–3), Category/Tag per queue; labeled agent answers available in extended versions

- Purpose
  Training models to classify, prioritize and route IT support email tickets; queue and priority prediction, plus analysis of multilingual customer support issues


# Dataset Name 2
  Customer Support Ticket Dataset

- Source
  https://www.kaggle.com/datasets/suraj520/customer-support-ticket-dataset

- Columns
  Ticket Subject (issue type), Ticket Description (free-text), plus additional operational fields (18 columns after transformation in Power BI project)  

- Purpose
  Multi-class support ticket categorization and IT helpdesk analytics

# Dataset Name 4
  Brazilian E-Commerce Public Dataset

- Source
  https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

- Rows
  ~100,000 orders with customer and reviews info

- Columns
  Multiple tables: customers (customer_id, customer_unique_id, city, state), orders (order_id, customer_id, status, timestamps), plus products, order_items, reviews, etc. 

- Purpose
  Customer profiling, order count, location, and VIP segmentation logic
